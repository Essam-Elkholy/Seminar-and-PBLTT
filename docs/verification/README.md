# Verification evidence

Store concise English verification notes and selected evidence here when actual tests have been performed. No verification results are included in this scaffold.

For each result, record the module/system, commit tested, testbench, tool/version, configuration, stimulus, expected behavior, actual result, pass/fail counts and remaining limitations.

Distinguish RTL checks from FPGA implementation/timing results and physical-board measurements. For image tests, record pixel mismatches, output coordinates/counts and the reference-model settings. Waveforms may support a result but do not replace expected-output checks.

Owners maintain local module tests; Essam coordinates system verification. Simulator launcher scripts and configuration files are outside this setup.
